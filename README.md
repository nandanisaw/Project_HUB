# Project_HUB
I develop to an interactive Super Market Sales Dashboard to analyse sales performance, customer behaviour, product trends, and revenue growth using excel.

# Dataset

Key Insight - Total Revenue, Total Orders, Total Tax, Total Quantity - Identified top performing product and customers, Analyzed monthly and yearly sales trends
